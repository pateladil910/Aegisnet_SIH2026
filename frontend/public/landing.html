The Problem

Disasters strike faster than traditional monitoring responds

India loses thousands of lives annually to environmental disasters that could be mitigated with early warning. Existing IoT solutions rely on centralised cloud processing — a fatal flaw when connectivity fails exactly when it's most needed.

  • ✓Cloud-dependent systems go dark when mobile towers flood or burn
  • ✓Single sensors produce false positives — cooking smoke triggering wildfire sirens
  • ✓Manual threshold checks create dangerous delays during multi-site surges
  • ✓No spatial correlation — a flooded upstream node can't warn downstream communities
  • ✓Authorities lack real-time AI confidence scores for escalation decisions

Core Features

Every layer engineered for resilience

AegisNet works when conventional systems fail — autonomously, intelligently, and in real time.

🌊
Flood Surge Detection
Ultrasonic HC-SR04 sensors track water level with 1mm precision. Rate-of-change edge AI detects flash surge within 2 seconds of threshold breach — no cloud dependency required.
🔥
Wildfire Early Warning
Multi-sensor fusion (IR flame sensor + MQ135 + DHT22 thermal) cross-validates ignition signatures. AI false-positive filter distinguishes wildfire from cooking smoke before any alarm fires.
🌫️
Industrial AQI Monitoring
MQ135 sensors continuously monitor particulate matter and hazardous gas concentrations. AQI breach events trigger tiered escalation with multilingual SMS alerts in Hindi and English.
📡
LoRa Mesh Networking
Self-healing multi-hop LoRa network on 433MHz. Nodes relay packets through available neighbours when direct paths fail. Upstream sensor can alert downstream community nodes autonomously.
🧠
Spatial Correlation AI
Inverse Distance Weighted (IDW) correlation engine analyses risk trends across neighbouring nodes within a 15km catchment radius. Computes Area Probability Index for actionable geo-level alerts.
☀️
Solar-Powered Autonomy
Each field node integrates a solar charging circuit for indefinite deployment. Battery state, charging status, and RSSI signal strength are broadcast with every telemetry heartbeat packet.

AI & Machine Learning

Two-tier intelligence: Edge + Cloud

On-device TinyML for speed and autonomy. Cloud correlation for accuracy and context. Zero single point of failure.

Level 1 · On-Device

Edge TinyML Engine

Runs entirely on the ESP32 microcontroller. No internet connection required. Computes a 0–100 multi-hazard risk vector every sensor cycle using statistical feature extraction and rate-of-change analysis.
